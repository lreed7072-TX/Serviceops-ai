# Plan 02: Prisma schema changes — new models and field additions

## Objective
Add the three new Prisma models (`QboSyncJob`, `QboAccountMap`, `QboCdcCursor`) and add QBO sync ID fields to five existing models (`QboConnection`, `Quote`, `Material`, `LaborRate`, `TimeEntry`). Run the migration to create database tables and regenerate the Prisma client. This is the schema foundation that Plans 03-05 depend on for typed access to these models.

## must_haves
- [ ] `QboSyncJob`, `QboAccountMap`, and `QboCdcCursor` models exist in `schema.prisma` with correct columns, indexes, and relations
- [ ] `QboConnection` has three new fields: `refreshTokenExpiry DateTime?`, `refreshInProgress Boolean @default(false)`, `refreshLockedAt DateTime?`
- [ ] `Quote`, `Material`, `LaborRate`, and `TimeEntry` each have their respective QBO entity ID fields
- [ ] `npx prisma migrate dev` completes without error and `npx tsc --noEmit` passes
- **Deferred:** `qboVendorId` is NOT added in this phase. Per CONTEXT.md decision, no standalone Vendor model exists yet — `qboVendorId` is deferred to Phase 5 (VEND-01) when the Vendor model is created.

<task id="02.02">
<title>Add QboSyncJob model to schema.prisma</title>
<action>
Add the `QboSyncJob` model to `prisma/schema.prisma`. Insert it after the `QboSyncLog` model block (after line 1738, before the Customer Portal section).

```prisma
model QboSyncJob {
  id           String    @id @default(uuid()) @db.Uuid
  orgId        String    @db.Uuid
  connectionId String    @db.Uuid
  entityType   String    // "customer" | "invoice" | "estimate" | "item" | "employee" | "vendor" | "timeActivity" | "expense" | "payment" | "creditMemo"
  entityId     String    @db.Uuid
  action       String    // "push" | "pull" | "void" | "email"
  priority     Int       @default(5) // 1=user-triggered real-time, 5=CDC-driven inbound, 9=bulk initial sync
  status       String    @default("pending") // "pending" | "claimed" | "completed" | "failed" | "dead_letter"
  payload      Json?
  attempts     Int       @default(0)
  maxAttempts  Int       @default(3)
  lockedAt     DateTime?
  lockedBy     String?   // Serverless instance identifier
  completedAt  DateTime?
  errorMessage String?   @db.Text
  createdAt    DateTime  @default(now())
  updatedAt    DateTime  @updatedAt

  org        Org           @relation(fields: [orgId], references: [id])
  connection QboConnection @relation(fields: [connectionId], references: [id])

  @@index([orgId, status, priority])
  @@index([status, lockedAt])
  @@index([orgId, entityType, entityId, status])
}
```
</action>
<verify>
Run: `grep -c "model QboSyncJob" prisma/schema.prisma` — should return 1.
Run: `grep -A2 "@@index.*status.*priority" prisma/schema.prisma` — should show the composite index.
</verify>
</task>
