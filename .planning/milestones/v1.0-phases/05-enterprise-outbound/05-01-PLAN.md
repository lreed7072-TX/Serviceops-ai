# Plan 05-01: Schema Migration + QBO Client Functions + Mapper Functions

## Objective
Build the entire foundation layer for Phase 5: Prisma schema additions (Vendor model, QboClassMap model, new fields on User/Material/StockMovement/QboConnection/Invoice), all 16 new QBO client CRUD functions, and all 6 new pure mapper functions. This plan has zero dependencies and everything in Waves 2-4 depends on it.

## must_haves
- Vendor model exists in Prisma schema with all fields (name, companyName, email, phone, address, city, state, postalCode, vendorType enum, tax1099, isActive, qboVendorId, qboSyncedAt, orgId FK, materials relation)
- VendorType enum exists (SUPPLIER, SUBCONTRACTOR, OTHER)
- QboClassMap model exists with @@unique([orgId, orderType]) constraint
- User model has qboEmployeeId String? field
- Material model has vendorId FK to Vendor
- StockMovement model has qboBillId String? and qboPurchaseId String? fields
- QboConnection model has classTrackingEnabled Boolean?, locationTrackingEnabled Boolean?, preferencesLastCheckedAt DateTime?
- Invoice model has qboCreditMemoId String? field
- Org model has vendors and qboClassMaps back-references
- qbo-client.ts exports 16 new functions: createEmployee, getEmployee, updateEmployee, createVendor, getVendor, updateVendor, createTimeActivity, getTimeActivity, createBill, getBill, createPurchase, createCreditMemo, getCreditMemo, getPreferences, createClass, queryClasses
- qbo-mapper.ts exports 6 new pure functions: toQboEmployee, toQboVendor, toQboTimeActivity, toQboBill, toQboPurchase, toQboCreditMemo
- All mapper functions are pure (no async, no I/O, no prisma imports)
- All monetary values in mappers pass through roundQboAmount()
- Build passes with zero TypeScript errors

**Employee CRUD (3 functions):**
```typescript
export async function createEmployee(connection: QboConnection, data: Partial<QboEmployee>): Promise<QboEmployee> {
  const response = await qboRequest(connection, "POST", "employee", data);
  return response.Employee;
}

export async function getEmployee(connection: QboConnection, qboEmployeeId: string): Promise<QboEmployee> {
  const response = await qboRequest(connection, "GET", `employee/${qboEmployeeId}`);
  return response.Employee;
}

export async function updateEmployee(connection: QboConnection, qboEmployeeId: string, data: Partial<QboEmployee>): Promise<QboEmployee> {
  const existing = await getEmployee(connection, qboEmployeeId);
  const merged = { ...existing, ...data, Id: existing.Id, SyncToken: existing.SyncToken };
  const response = await qboRequest(connection, "POST", "employee", merged);
  return response.Employee;
}
```

**Vendor CRUD (3 functions):** Same pattern as Employee — createVendor, getVendor, updateVendor. Response key is `Vendor`.

**TimeActivity (2 functions):** createTimeActivity (POST `timeactivity`, response.TimeActivity), getTimeActivity (GET `timeactivity/{id}`, response.TimeActivity). No update — time activities are immutable in QBO.

**Bill (2 functions):** createBill (POST `bill`, response.Bill), getBill (GET `bill/{id}`, response.Bill).

**Purchase (1 function):** createPurchase (POST `purchase`, response.Purchase).

**CreditMemo (2 functions):** createCreditMemo (POST `creditmemo`, response.CreditMemo), getCreditMemo (GET `creditmemo/{id}`, response.CreditMemo).

Note: No entity ID in path — one preferences object per company.

<title>QBO mapper functions: toQboEmployee, toQboVendor, toQboTimeActivity, toQboBill, toQboPurchase, toQboCreditMemo</title>
<details>
Add 6 new exported pure functions to `src/lib/qbo/qbo-mapper.ts`. All are synchronous, no I/O, no async, no prisma imports.

**Import additions:** Add Prisma types needed: `User`, `StockMovement`, `TimeEntry` (check which are already imported). Add QBO types: `QboEmployee`, `QboVendor`, `QboTimeActivity`, `QboBill`, `QboPurchase`, `QboCreditMemo`, `QboRef` from `./qbo-types`.

**1. toQboEmployee:**
```typescript
export function toQboEmployee(
  user: Pick<User, "name" | "email">,
  existingQbo?: QboEmployee
): Partial<QboEmployee>
```
- DisplayName: `user.name ?? user.email.split("@")[0]`
- GivenName/FamilyName: split `user.name` on first space
- PrimaryEmailAddr: `{ Address: user.email }`
- BillableTime: `true`
- Merge pattern: spread `existingQbo` first if provided

**2. toQboVendor:**
```typescript
export function toQboVendor(
  vendor: Pick<Vendor, "name" | "companyName" | "email" | "phone" | "address" | "city" | "state" | "postalCode" | "tax1099">,
  existingQbo?: QboVendor
): Partial<QboVendor>
```
- DisplayName: `vendor.name`
- CompanyName: `vendor.companyName` if provided
- PrimaryEmailAddr: `{ Address: vendor.email }` if email provided
- PrimaryPhone: `{ FreeFormNumber: vendor.phone }` if phone provided
- BillAddr: build from address/city/state/postalCode if any provided
- Vendor1099: `vendor.tax1099`
- PrintOnCheckName: `vendor.companyName ?? vendor.name`

**3. toQboTimeActivity:**
```typescript
export function toQboTimeActivity(
  timeEntry: Pick<TimeEntry, "startedAt" | "accumulatedSeconds" | "notes">,
  qboEmployeeId: string,
  qboCustomerId: string,
  options?: { qboItemId?: string; classRef?: QboRef; billable?: boolean; hourlyRate?: number }
): Partial<QboTimeActivity>
```
- TxnDate: format `timeEntry.startedAt` as `YYYY-MM-DD`
- NameOf: `"Employee"`
- EmployeeRef: `{ value: qboEmployeeId }`
- CustomerRef: `{ value: qboCustomerId }`
- ItemRef: `{ value: options.qboItemId }` if provided
- ClassRef: `options.classRef` if provided
- Hours: `Math.floor(timeEntry.accumulatedSeconds / 3600)`
- Minutes: `Math.round((timeEntry.accumulatedSeconds % 3600) / 60)`
- BillableStatus: `options?.billable === false ? "NotBillable" : "Billable"`
- HourlyRate: `options?.hourlyRate ? { value: roundQboAmount(options.hourlyRate) } : undefined`
- Description: `timeEntry.notes`

**4. toQboBill:**
```typescript
export function toQboBill(
  stockMovement: Pick<StockMovement, "totalCost" | "unitCost" | "quantity" | "reference" | "notes" | "createdAt">,
  material: Pick<Material, "name">,
  qboVendorId: string,
  expenseAccountRef: { value: string; name?: string },
  options?: { classRef?: QboRef }
): Partial<QboBill>
```
- VendorRef: `{ value: qboVendorId }`
- TxnDate: format createdAt as YYYY-MM-DD
- DocNumber: `stockMovement.reference` if provided
- Line: single AccountBasedExpenseLineDetail line with Amount = `roundQboAmount(stockMovement.totalCost)`, AccountRef = expenseAccountRef, ClassRef = options.classRef, Description = `material.name + " x" + quantity`

**5. toQboPurchase:**
```typescript
export function toQboPurchase(
  stockMovement: Pick<StockMovement, "totalCost" | "reference" | "notes" | "createdAt">,
  material: Pick<Material, "name">,
  expenseAccountRef: { value: string; name?: string },
  options?: { classRef?: QboRef }
): Partial<QboPurchase>
```
- PaymentType: `"Cash"` (neutral default)
- AccountRef: expenseAccountRef (use same expense account as payment account for MVP — Purchase.AccountRef will match the line expense account to avoid needing a 6th mapping category)
- TxnDate: format createdAt as YYYY-MM-DD
- DocNumber: stockMovement.reference
- Line: AccountBasedExpenseLineDetail with Amount, AccountRef=expenseAccountRef, ClassRef, Description

**6. toQboCreditMemo:**
```typescript
export function toQboCreditMemo(
  invoice: Pick<Invoice, "total" | "invoiceNumber" | "notes">,
  lineItems: Array<Pick<InvoiceLineItem, "description" | "totalPrice" | "quantity" | "unitPrice">>,
  qboCustomerId: string,
  qboInvoiceId: string,
  options?: { classRef?: QboRef }
): Partial<QboCreditMemo>
```
- CustomerRef: `{ value: qboCustomerId }`
- LinkedTxn: `[{ TxnId: qboInvoiceId, TxnType: "Invoice" }]`
- ClassRef: options.classRef at transaction level
- DocNumber: `"CM-" + invoice.invoiceNumber`
- CustomerMemo: invoice.notes if provided
- Line: map each lineItem using same pattern as existing `toQboInvoiceLine()` — SalesItemLineDetail with Amount = roundQboAmount(totalPrice), Qty, UnitPrice, Description
