# Plan 05-04: Unit Tests for All Phase 5 Functions

## Objective
Write comprehensive unit tests covering all Phase 5 mapper functions, sync functions, class tracking helpers, preferences caching, and flush dispatcher extensions. Follow the established test patterns from Phase 3-4 (vitest, vi.mock for prisma/qbo-client, assert on call arguments and return values).

## must_haves
- Mapper tests: toQboEmployee, toQboVendor, toQboTimeActivity, toQboBill, toQboPurchase, toQboCreditMemo all tested
- Mapper tests verify merge pattern (existingQbo spread) and roundQboAmount usage
- Sync tests: syncVendorToQbo, syncEmployeeToQbo tested with create and update paths
- Sync tests: syncTimeEntryToQbo tested with cascade employee/customer sync, STOPPED guard, billable/non-billable
- Sync tests: syncExpenseToQbo tested with Bill path (vendor present) and Purchase path (no vendor)
- Sync tests: syncCreditMemoToQbo tested with LinkedTxn to original invoice
- Class tracking tests: resolveOrCreateQboClass tested with enabled/disabled, cache hit, auto-create, error fallback
- Preferences tests: fetchAndCachePreferences tested with class+location flags extraction
- Flush dispatcher tests: all 5 new cases route correctly
- All tests pass: `npx vitest run src/__tests__/lib/qbo/ --reporter=verbose`
- Zero regressions in existing test suite
